## Qué significa

**CP** suele usarse para hablar del *Combat Power*: una cifra que resume parte del poder de tu personaje. Es útil para observar progreso y comparar cambios, pero no explica por sí sola cómo juegas ni si un equipo está bien construido.

## Para qué sí sirve

- Ver si una mejora aumenta el poder general.
- Registrar tu evolución con el tiempo.
- Tener una referencia aproximada para cierto contenido.
- Detectar que un cambio de equipo produjo una diferencia.

## Para qué no sirve

El CP no reemplaza:

- conocimiento de mecánicas;
- uso correcto de habilidades;
- resistencias o atributos necesarios para una situación;
- experiencia en una ruta de dungeon;
- coordinación con el grupo.

Dos personajes con una cifra parecida pueden rendir de manera diferente porque tomaron decisiones distintas.

## La regla de CODE

No uses el CP como una etiqueta social. En nuestro guild **Junior, Senior y Core no son divisiones de poder**. Un Senior es alguien que comparte experiencia; un Core es alguien comprometido con la comunidad.

## Antes de perseguir más CP

Pregunta:

1. ¿Qué contenido quiero hacer?
2. ¿Qué me está limitando ahora: daño, supervivencia o conocimiento?
3. ¿La mejora que considero resuelve ese límite?
4. ¿Entiendo el costo total?

Una subida de CP es mejor cuando también entiendes por qué ocurrió.
