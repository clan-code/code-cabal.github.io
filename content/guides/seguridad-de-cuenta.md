## Regla principal

Ningún miembro de CODE necesita tus credenciales para ayudarte. No compartas ID, contraseña, sub-password, códigos 2FA, respuestas secretas ni correo de cuenta.

## Señales de alerta

- Un premio exige iniciar sesión desde un enlace enviado por chat.
- El dominio se parece al oficial, pero tiene letras o guiones diferentes.
- Te amenazan con cerrar la cuenta si no respondes de inmediato.
- Alguien afirma ser administrador y pide datos secretos.
- Una descarga promete Alz, automatización o ventajas externas.
- Te solicitan acceso remoto para “configurar” el juego.

## Qué hacer

1. No abras el enlace desde el mensaje.
2. Entra al portal oficial usando una dirección guardada por ti.
3. Cambia tus credenciales desde el sitio oficial si ya las compartiste.
4. Revisa sesiones y seguridad de tu correo.
5. Contacta al [soporte oficial de PlayThisGame](https://www.playthisgame.com/CM/en/Support/Home).
6. Avisa al guild para que otras personas no caigan.

## Sobre esta web

La web de CODE no tiene login, pagos ni formularios de cuenta. El generador de reclutamiento solo crea texto en tu navegador y no envía información a ningún servidor.
