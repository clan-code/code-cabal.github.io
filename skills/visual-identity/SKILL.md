# Identidad visual

## Dirección

Fantasía tecnológica oscura, comunidad, conocimiento y progreso. Paleta base: negro azulado, cian, rojo profundo y oro.

## Reglas

- CODE es una comunidad antes que una referencia a programación.
- No usar terminales, bloques de código, Rust o Python como motivo dominante.
- No copiar personajes, logotipos o pantallas oficiales.
- Nunca generar texto dentro de una imagen destinada a recibir texto HTML.
- Mantener zonas de descanso para títulos y botones.
- Asegurar contraste mediante overlays CSS, no quemando texto en el arte.

## Flujo de un activo

1. Definir objetivo, relación de aspecto y espacio para contenido.
2. Generar una composición original.
3. Revisar anatomía, armas, manos, símbolos y texto accidental.
4. Recortar y optimizar a WebP.
5. Crear variante móvil cuando el encuadre cambie.
6. Añadir alt y registrar el activo en `design/asset-manifest.toml`.
7. Verificar peso y apariencia en 360 px.

## Presupuestos

- Hero: ideal < 350 KB.
- Portada de sección: ideal < 150 KB.
- Icono: ideal < 60 KB.
- Screenshot: ideal < 250 KB.
