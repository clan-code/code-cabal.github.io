# Seguridad

## Este proyecto nunca debe solicitar

- ID de PlayThisGame.
- Contraseña o sub-password.
- Códigos 2FA.
- Respuestas secretas.
- Correo asociado a una cuenta.
- eCoins, Alz o acceso remoto al equipo.

## Reportar un problema

No publiques secretos en un issue. Contacta directamente al Guild Master `zRust` dentro de CABAL Online NA y comparte únicamente información técnica no sensible.

## Alcance

El sitio es estático. No tiene backend, autenticación ni almacenamiento de formularios. Una modificación que agregue alguno de esos elementos requiere una decisión de arquitectura explícita y revisión de seguridad.
